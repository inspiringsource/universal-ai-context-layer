# UACL Context: universal-ai-context-layer-demo

> Portable, model-independent project context generated by Universal AI Context Layer.

## Project Summary

A vendor-neutral context layer that preserves project knowledge across AI models, tools, and agents.

## Project Goals

- Keep architecture decisions available across Claude, ChatGPT, Cursor, Codex, and Gemini.
- Give specialized agents one shared source of truth.

## Tech Stack

- Python 3.11
- Typer
- PyYAML

## Architecture

- `src/ai_context_map/cli.py`: backward-compatible UACL command-line entry point
- `src/ai_context_map/commands/`: workflow orchestration
- `src/ai_context_map/emitter/`: canonical and portable context outputs

## Current Tasks

- Validate UACL context handoffs with multiple AI tools.

## Decisions

- **Canonical YAML context:** YAML is readable, editable, and version-control friendly.
- **Model-independent exports:** Markdown and JSON avoid coupling UACL to one model.

## Constraints

- Do not send repository content to remote services automatically.
- Preserve human-authored context when refreshing generated repository intelligence.

## Known Issues

- Concurrent agent updates are not automatically merged.

## AI Instructions

- Read the complete UACL context before proposing changes.
- Record durable architecture decisions in the canonical context.

## Agent Roles

- **Coordinator Agent:** Maintains priorities and delegates scoped work.
- **Coding Agent:** Implements current tasks within recorded constraints.
- **Reviewer Agent:** Validates changes against goals and decisions.
