# Compiled Context: universal-ai-context-layer-demo

> Generated by Universal AI Context Layer (UACL) for AI-assisted development.

## Project Summary

UACL generates, validates, and refreshes AI-consumable context from repository analysis and maintained project knowledge.

## Project Goals

- Keep AGENTS.md and related context outputs aligned with repository changes.
- Preserve human-authored decisions when generated analysis is refreshed.

- README and documentation

- `.ai/context.yaml`

## Generated Outputs
