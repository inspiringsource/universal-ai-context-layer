# Compiled Context: universal-ai-context-layer-demo

> Generated by Universal AI Context Layer (UACL) for AI-assisted development.

## Project Summary

A context compiler that generates and validates AI-consumable project context.

## Project Goals

- Keep AGENTS.md and related context outputs aligned with repository changes.
- Preserve human-authored decisions when generated analysis is refreshed.

## Tech Stack

- Python 3.11
- Typer
- PyYAML

## Architecture

- `src/ai_context_map/cli.py`: backward-compatible UACL command-line entry point
- `src/ai_context_map/commands/`: workflow orchestration
- `src/ai_context_map/emitter/`: canonical and compiled context outputs

## Current Tasks

- Improve context-source ingestion and drift validation.

## Decisions

- **Canonical YAML context:** YAML is readable, editable, and version-control friendly.
- **Support AGENTS.md:** Compile an established repository instruction format instead of replacing it.

## Constraints

- Never overwrite a root AGENTS.md without an explicit force flag.
- Preserve human-authored context when refreshing generated repository intelligence.

## Known Issues

- Concurrent agent updates are not automatically merged.
- Documentation and ADR ingestion is currently lightweight.
- Drift checks are timestamp- and reference-based.

## AI Instructions

- Run `aicontext check` before publishing compiled outputs.
- Read the complete UACL context before proposing changes.
- Record durable architecture decisions in the canonical UACL context.

## Validation Warnings

- None recorded.

## Agent Roles

- **Coordinator Agent:** Maintains priorities and delegates scoped work.
- **Coding Agent:** Implements current tasks within recorded constraints.
- **Reviewer Agent:** Validates changes against goals and decisions.
